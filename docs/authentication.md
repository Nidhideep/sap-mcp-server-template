# Authentication

SAP MCP servers support three auth methods, configured via `AUTH_METHOD` in `.env`.

---

## Methods

### 1. Token (`AUTH_METHOD=token`) — Recommended

Use a Bearer token generated by your SAP identity provider (SAP IAS, Azure AD, Okta).

```env
AUTH_METHOD=token
SAP_TOKEN=eyJhbGciOiJSUzI1NiJ9...
```

Token refresh is your responsibility — the server does not auto-refresh. Rotate via your CI/CD secret manager or a sidecar.

**When to use:** API-to-API integrations, cloud-deployed MCP servers, SSO environments.

---

### 2. Basic (`AUTH_METHOD=basic`)

HTTP Basic auth with SAP username and password.

```env
AUTH_METHOD=basic
SAP_USERNAME=your_sap_user
SAP_PASSWORD=your_sap_password
```

**Warning:** Basic auth sends credentials on every request. Use only over HTTPS. Prefer token auth wherever possible.

**When to use:** Development, on-prem SAP systems without SSO, RFC-based integrations.

---

### 3. SSO (`AUTH_METHOD=sso`)

Placeholder for enterprise SSO token acquisition (OIDC, SAML, SAP IAS OAuth2).

The implementation is intentionally left incomplete — add your token provider in `config/auth.ts`:

```ts
case "sso": {
  const token = await acquireTokenFromYourProvider();
  return { ...base, Authorization: `Bearer ${token}` };
}
```

**When to use:** Enterprise deployments where tokens are issued by a central IdP.

---

## Secret Storage

| Where to store | Where NOT to store |
|----------------|--------------------|
| `.env` (gitignored) | `config/auth.ts` |
| CI/CD secret manager | `.mcp.json` (committed) |
| System keychain | `CLAUDE.md` or `README.md` |
| AWS Secrets Manager / Azure Key Vault | Any file tracked by git |

**Never commit credentials.** The `.gitignore` blocks `.env` and `.mcp.json`.

---

## SAP Client

Set `SAP_CLIENT` to your SAP system client (Mandant) number. Default is `100`.

```env
SAP_CLIENT=200
```

This is sent as the `sap-client` HTTP header on every request.

---

## CSRF Tokens

For SAP OData write operations (POST, PATCH, DELETE), SAP may require a CSRF token. Add this to your write tool flow:

```ts
// Fetch CSRF token before write
const fetchResponse = await fetch(sapUrl("/sap/opu/odata/sap/YOUR_SERVICE_SRV/"), {
  method: "GET",
  headers: { ...getAuthHeaders(), "X-CSRF-Token": "Fetch" },
});
const csrfToken = fetchResponse.headers.get("x-csrf-token");

// Use in write request
await fetch(endpoint, {
  method: "POST",
  headers: { ...getAuthHeaders(), "X-CSRF-Token": csrfToken },
  body: JSON.stringify(payload),
});
```
